description: A tiny sample showing the Earful script format.

THEO: Here's the whole format in a few lines. (beat) It's just a script you can read.

MARA: Every line starts with a host cue — a name and a colon. Anything before the first cue, like this note, is ignored.

THEO: Parentheticals are direction, stripped from the audio. Use (pause: 200) for an exact beat, or the named ones — (beat), (pause), (long pause).

MARA: A trailing ellipsis is a soft trail-off... like that. A single period is just a period.

THEO: End a line with a dash and the other host talks over you —

MARA: — and I cut right in.

THEO: (faster) A pace note at the very start of a line speeds the whole line up.

MARA: Pronunciations go inline with IPA, so a [skua](/skˈuːə/) comes out right. Anything else in parentheses, like (dryly), is just a note to yourself.
